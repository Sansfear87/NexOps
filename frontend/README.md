# Frontend Package: AI DevOps Assistant

**Framework:** React 18 with TypeScript and Vite  
**Status:** Phase 0 Minimal Foundation Placeholder  

## Overview
This directory contains the Single-Page Application (SPA) developer console for the AI DevOps Assistant.
Full UI development begins in **Phase 13 (Frontend)**.

## Commands
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Typecheck and build production bundle
npm run build
```
